# Projeto: Renan Santos - Landing Page

## Visão geral

Este projeto é uma landing page institucional criada para apresentar a candidatura de Renan Santos, com foco em comunicação visual forte, proposta de campanha e captação de apoio de voluntários.

A estrutura foi desenvolvida em HTML, CSS e JavaScript puros, com layout responsivo e elementos de destaque para transmitir uma identidade política moderna e impactante.

## Objetivo

O site tem como objetivo:

- Apresentar a proposta de liderança e visão do candidato;
- Comunicar valores, missão e propostas de governo;
- Gerar engajamento com a audiência;
- Capturar contatos de apoiadores por meio de formulário de apoio;
- Servir como base visual para campanha digital.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Formulário integrado com SheetMonky para coleta de dados

## Funcionalidades principais

### 1. Header e navegação
- Menu fixo no topo da página;
- Links internos para as seções do site;
- Botão de destaque para mobilização de apoiadores.

### 2. Hero section
- Apresentação visual forte com frase principal e chamada para ação;
- Destaque para a missão e identidade da campanha;
- Botões de ação para conhecer propostas e apoiar o projeto.

### 3. Seção "Quem sou"
- Apresenta a visão e a mensagem do candidato;
- Explica a proposta de uma liderança centrada em missão, trabalho e futuro.

### 4. Seção de propostas
- Cinco pilares principais: segurança, moradia, trabalho, economia e educação;
- Cards com métricas e objetivos de transformação;
- Comunicação visual para destacar resultados esperados.

### 5. Formulário de apoio
- Campos de nome, e-mail e estado;
- Envio de dados para plataforma externa via action do formulário;
- Estrutura preparada para captar voluntários e apoiadores.

### 6. Interações em JavaScript
- Menu mobile responsivo;
- Efeito de revelação ao rolar a página;
- Fechamento automático do menu em navegação interna.

## Como executar localmente

1. Abra a pasta do projeto no editor de código.
2. Certifique-se de que os arquivos `index.html`, `styles.css` e `script.js` estejam na raiz do projeto.
3. Abra o arquivo `index.html` em um navegador.

Você também pode usar um servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```bash
http://localhost:8000
```

## Observações

- O projeto foi desenvolvido como landing page estática;
- O formulário está configurado para envio externo e pode ser ajustado conforme a plataforma de coleta de dados escolhida;
- As imagens localizadas na pasta `img` são essenciais para a identidade visual do site;
- A página foi pensada para campanhas políticas digitais, com foco em branding e conversão.

## Possíveis melhorias futuras

- Adicionar área de contato com redes sociais reais;
- Integrar formulário com backend ou CRM;
- Incluir mais seções, como depoimentos, agenda e notícias;
- Otimizar para SEO e acessibilidade;
- Tornar a página ainda mais responsiva para dispositivos móveis.

## Resumo

Este projeto é uma campanha digital institucional em formato de landing page, com foco em apresentação da candidatura, consolidação da marca e captação de apoio popular. A experiência visual foi pensada para causar impacto imediato, reforçando a mensagem de liderança, mudança e futuro.
